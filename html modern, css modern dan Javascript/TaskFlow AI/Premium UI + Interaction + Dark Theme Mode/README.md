# AgentTaskFlow-AI

Task manager premium dengan UI dark modern. **100% frontend** — data disimpan di `localStorage` browser.

## Fitur
- ✅ CRUD tugas (tambah, toggle selesai, hapus)
- 🎯 Filter: Semua, Aktif, Selesai, Prioritas Tinggi
- 🔍 Pencarian realtime
- 🔥 Prioritas: Rendah, Sedang, Tinggi
- 📊 Statistik & progress bar
- 📱 Responsive (mobile drawer sidebar)
- 🎨 Dark premium UI, glassmorphism, ambient glow

## Menjalankan
1. Ekstrak folder `AgentTaskFlow-ai/`
2. Buka `AgentTaskFlow-ai.html` langsung di browser, **ATAU**
3. Jalankan server lokal:
   ```bash
   # Python 3
   python -m http.server 8000
   # Node.js (jika ada http-server)
   npx http-server -p 8000
