
# Nova CRM Dashboard

Dashboard CRM premium berbasis HTML, CSS, dan JavaScript vanilla.

## Menjalankan
1. Simpan semua file dalam folder yang sama.
2. Buka `index.html` menggunakan browser modern.
3. Tidak memerlukan instalasi dependency, framework, atau build tools.

## Interaksi
- Toggle Light/Dark Mode.
- Preferensi tema disimpan di localStorage browser.
- Pencarian kontak langsung.
- Shortcut pencarian Ctrl+K atau Cmd+K.
- Tambah kontak menggunakan dialog dan validasi form.
- Pilih semua kontak yang terlihat.
- Ekspor kontak yang terlihat menjadi CSV.
- Tambah tugas dan tandai tugas selesai.
- Navigasi sidebar responsif.
- Notifikasi toast untuk aksi UI.

## Batasan
Ini adalah proyek UI frontend demo. Data kontak awal, revenue,
pipeline, dan statistik bukan data bisnis nyata. Kontak dan tugas
yang ditambahkan tidak disimpan permanen. Tidak ada backend,
database, autentikasi, API, atau sinkronisasi cloud. Grafik revenue
merupakan ilustrasi SVG, bukan visualisasi dari data live.

Google Fonts memerlukan koneksi internet; font fallback tersedia.
