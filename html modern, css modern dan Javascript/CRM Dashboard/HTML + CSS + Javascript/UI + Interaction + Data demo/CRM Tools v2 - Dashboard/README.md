# CRM Tools V2 — Dashboard

> Dashboard CRM modern dengan **light premium & dark mode**, dibangun murni menggunakan **HTML + CSS + JavaScript** (tanpa framework, tanpa build step). Semua fitur UI, interaksi, dan data demo sudah berjalan dan siap dijalankan langsung di browser.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🌗 **Light & Dark Mode** | Tema premium yang bisa diganti via topbar atau halaman Settings. Pilihan tersimpan di `localStorage`. |
| 📊 **Dashboard Analytics** | Statistik KPI, chart revenue (Canvas native), pipeline per stage, deals terbaru, dan feed aktivitas. |
| 👥 **Manajemen Kontak** | Tabel kontak dengan pencarian real-time dan filter status (Customer / Lead / Prospect). |
| 📋 **Kanban Pipeline** | Board drag-and-drop antar stage (Lead → Qualified → Proposal → Negotiation → Won). |
| ✅ **Manajemen Tugas** | Checklist interaktif dengan badge counter di sidebar. |
| 📈 **Laporan** | Statistik performa dan grafik konversi bulanan. |
| ⚙️ **Pengaturan** | Toggle dark mode, notifikasi email, dan auto-save filter. |
| 🔍 **Global Search** | Cari kontak, deal, atau tugas — otomatis navigasi ke halaman terkait. |
| 🔔 **Toast Notification** | Feedback instan untuk setiap aksi pengguna. |
| 📱 **Responsive Design** | Sidebar collapsible, layout adaptif untuk desktop, tablet, dan mobile. |
