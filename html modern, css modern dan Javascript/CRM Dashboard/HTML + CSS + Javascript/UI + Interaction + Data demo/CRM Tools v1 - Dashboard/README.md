
# CRM Dashboard

CRM Dashboard adalah project front-end menggunakan HTML, CSS,
dan JavaScript murni.

## Cara menjalankan

1. Buat folder bernama `crm-dashboard`.
2. Buat file `index.html`.
3. Buat folder `css`, lalu file `style.css`.
4. Buat folder `js`, lalu file `data.js` dan `app.js`.
5. Salin setiap kode ke file yang sesuai.
6. Buka `index.html` menggunakan browser modern.

Opsional, gunakan VS Code dengan ekstensi Live Server.

## Fitur

- Dashboard ringkasan KPI.
- Grafik revenue demo.
- Sales pipeline.
- Pencarian kontak dan filter status.
- Tambah dan hapus kontak.
- Ekspor kontak ke CSV.
- Checklist tugas.
- Light mode dan dark mode.
- Responsive layout untuk desktop dan mobile.
- Penyimpanan lokal melalui localStorage.

## Catatan

Project ini tidak memakai backend atau API sungguhan.
Data demo dan perubahan kontak/tugas disimpan di browser lokal.
Data tidak otomatis tersinkronisasi antarperangkat.


Cara menjalankan
1. Buat struktur folder sesuai bagian pertama.
2. Pastikan nama file dan lokasi folder sama persis.
3. Simpan semua kode.
4. Buka index.html di Chrome, Edge, Firefox, atau browser modern lainnya.
