Report notes & definitions

Understand the sample metrics displayed in JProMan.

How is on-time delivery represented?
The percentage is a static illustrative metric for this UI demo. No live project deadlines or task records are being queried.
Can I export reports?
Export controls are not connected in this HTML/CSS-only edition. A real export requires JavaScript or a server-side reporting workflow.
How can I connect a real workspace?
A production SaaS version would need authentication, a database, authorization rules, and API endpoints. None are included in this static front-end prototype.
