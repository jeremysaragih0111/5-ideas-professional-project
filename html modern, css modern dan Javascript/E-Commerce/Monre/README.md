Cara menjalankan dan menguji

1. Simpan source code HTML, CSS, dan JavaScript masing-masing ke file index.html, style.css, dan app.js.
2. Letakkan ketiganya dalam folder yang sama.
3. Buka index.html di browser, atau gunakan Live Server di Visual Studio Code.
4. Tambahkan produk melalui tombol tambah produk.
5. Coba pencarian, filter status, detail pesanan, dan perubahan status.
6. Klik ekspor untuk mengunduh CSV.
